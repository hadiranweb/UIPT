# مرجع APIهای اکوسیستم ONSOUR (Foundation Level 1.3)

این سند مرجع رسمی APIهای هسته، ران‌تایم و هاب در نسخه ۱.۳ است.

---

## ۱. هسته محاسباتی (`rts_core`)

### ساختارهای داده
- `Node`: نود مینیمال (۱۶ بایت).
- `NodePractical`: نود کاربردی (۳۲ بایت، Aligned).
- `Edge`: یال گراف (۱۶ بایت).

### توابع اصلی
- `step_sparse_buffered`: اجرای گام زمانی با بافر دوگانه.
- `step_sparse_js`: واسط WASM.

---

## ۲. ران‌تایم جزیره‌ای (`island_runtime`)

### ساختار `Island`
مدیریت وضعیت و اجرای اپوک‌ها برای یک گراف مستقل.
- `Island::new(num_nodes, edges)`: ایجاد جزیره جدید.
- `island.step()`: اجرای یک گام زمانی کامل (Gather + Apply + Swap).

### تراویت `OnsourModule`
اینترفیس استاندارد برای توسعه ماژول‌های جدید:
- `id()`: شناسه ماژول.
- `init()`: مقداردهی اولیه.
- `update(dt)`: به‌روزرسانی در هر اپوک.

---

## ۳. هاب سیناپسی (`synaptic_hub`)
نقطه ورود ارکستراسیون سیستم (Tokio-based binary).
- مدیریت چرخه حیات جزایر.
- مدیریت لاگ‌ها و وضعیت کلی سیستم.
